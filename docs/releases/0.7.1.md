# Guixvis 0.7.1

September 25, 2026

This patch fixes two things that got in the way of reading package relationships.

## Search inside Reverse deps

Typing in the terminal's Reverse deps tab now filters the dependents of the
package you selected in Overview. Previously it edited the global search,
which could silently switch the package underneath the reverse tree.

The local filter matches package names without regard to case. It includes
direct dependents and the existing depth-limited transitive set, even when the
Transitive section is collapsed. The traversal limits still apply; this is
not an exhaustive search of every possible path through the catalog.

Use arrows or page keys to browse matches, Backspace to edit, and Esc or
Ctrl+U to clear. Switching tabs keeps the filter; selecting a different
Overview package clears it. Printable letters and digits are search input
in this tab, including keys that act as shortcuts elsewhere. Tab / Shift+Tab
still change tabs, and Ctrl+C quits.

## Readable rectangle labels

The browser's rectangle view no longer shapes text at a tiny fractional font
size before enlarging it with the graph. That mismatch compressed the letters
even though the boxes had been measured with a normal font. Labels now use
consistent measurement and drawing coordinates. Package names remain inside
their boxes as you zoom, and long names still shorten with an ellipsis.

There is no need to reduce the browser to 75% zoom to compensate. Node picking,
dragging, panning, and right-click Back retain their existing behavior.

## Downloads and checks

The source package is `guixvis-0.7.1.zupt`, an unencrypted level-9 ZUPT archive
of the tagged source, with `SHA256SUMS`. Run `sha256sum -c SHA256SUMS` and
`zupt test guixvis-0.7.1.zupt` before extracting. No `.tar.gz` release asset
is uploaded.

Regression tests cover the local filter and rectangle text transforms. The
[usage guide](../usage.md) explains the controls, and the
[publishing guide](../releasing.md) lists the full test, archive, and native
Guix installation checks. No application dependencies were added.
